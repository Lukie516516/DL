# 可调整参数控制板清单

本文给权限后台 / leader 控制板使用。核心是回答三个问题：

```text
1. 后台可以调什么功能？
2. 前端读哪个 function？
3. 管理员写哪个 function？
```

后台第一版建议分成两类：

| 类型 | 说明 |
| --- | --- |
| 可开放给运营后台 | 价格、费率、开关、时间、白名单 |
| 只建议技术/多签/DAO 操作 | 核心地址、权限、实现合约、信用写入者、DealCoin（DC）增发权限 |

### 用户侧 NFT 资料功能

这些不是 leader 权限后台参数，是 NFT 持有人自己改资料：

| 用户功能 | 合约 | 读取 function | 修改 function | 谁能操作 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 设置头像 URL | `DealInfoNFT` | `imageOf(uint256 tokenId)` | `setTokenImageURI(uint256 tokenId, string uri)` | NFT owner / approved | 推荐方案。前端先上传图片到服务器/IPFS/OSS，再把 URL 写链上。 |
| 设置链上头像数据 | `DealInfoNFT` | `imageOf(uint256 tokenId)` | `setTokenImageData(uint256 tokenId, string mime, bytes data)` | NFT owner / approved | 传原始图片 bytes 的 `0x...`，不是 base64。合约读取时会转成 `data:mime;base64,...`。 |
| 设置 NFT 昵称/展示名 | `DealInfoNFT` | `username(uint256 tokenId)` | `setTokenUserName(uint256 tokenId, string name)` | NFT owner / approved | 前端截图里的“NFT 名称”对应这个字段。最大 64 bytes。 |
| 设置关于我 | `DealInfoNFT` | `userdetail(uint256 tokenId)` | `setTokenUserDetail(uint256 tokenId, string detail)` | NFT owner / approved | 最大 1000 bytes。 |

注意：

```text
tokenURI 里的标准 name 当前仍是 Deal Info NFT + displayNo。
前端展示用户自定义名称时，应读 username(tokenId)。
如果同时设置了 imageURI 和 imageData，imageOf(tokenId) 优先返回 URI。
```

| 参数 | 当前值 |
| --- | --- |
| top 关系快照数量 | `TOP_K = 5` |
| 额外奖励最低系数 | `MIN_EXTRA_BPS = 100`，即 0.01x |
| 额外奖励最高系数 | `MAX_EXTRA_BPS = 20000`，即 2x |

| 授权暂停 DealCoin（DC） | `DCToken` | `hasRole(PAUSER_ROLE, account)` | `grantRole(PAUSER_ROLE, account)` | DEFAULT_ADMIN_ROLE | 应急权限。 |
| 暂停 / 恢复 DealCoin（DC） | `DCToken` | `paused()` | `pause()` / `unpause()` | PAUSER_ROLE | 应急按钮可做，但必须二次确认。 |
| D 总量 | `D` | `MAX_SUPPLY()` | 不可调 | - | 固定 100 D。 |
| D 精度 | `D` | `decimals()` | 不可调 | - | 固定 18 位。 |
| D 席位门槛 | `D` | `SEAT_THRESHOLD()` | 不可调 | - | 固定 2.5 D。 |

## 13. 第一版不建议开放普通按钮

| 不建议开放项 | 原因 |
| --- | --- |
| treasury 地址 | 改错会导致协议收入进错地址。 |
| DealCoin（DC）minter 权限 | 改错会导致 DealCoin（DC）被无限增发。 |
| Factory / Implementation 地址 | 改错会导致新 deal 创建失败或逻辑变化。 |
| CreditGraph recorder 权限 | 改错会让未授权地址写信用分。 |
| Pair 初始化 / 映射已有 pair | 直接影响价格和 swap 资产安全。 |
| 虚拟流动性 | 直接影响报价，属于高风险调参。 |
| 分红 executor | 改错会导致分红开轮权限丢失。 |

## 14. 前端展示规则

| 参数类型 | 前端输入方式 |
| --- | --- |
| 金额 | 用户填正常数量，前端按 token decimals 转 wei。 |
| bps | 用户填百分比，前端转 bps。例如 20% = 2000。 |
| 时间 | 用户填秒/分钟/小时/天，前端统一转秒。 |
| 地址 | 校验非零地址，显示当前值和新值。 |
| 高风险操作 | 二次确认，展示影响范围。 |
| 权限 | 页面进入时先判断当前钱包是否有 owner/admin/role。无权限只读。 |
