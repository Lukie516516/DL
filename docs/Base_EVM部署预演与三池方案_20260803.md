# Base EVM 部署预演与三池方案

状态：本地配置、只读预检和 Base mainnet fork 全协议部署预演已通过。未发送 Base 主网交易，未初始化真实流动性。

## 链和资产

| 用途 | 资产 | Base mainnet 地址 | 精度 | 说明 |
| --- | --- | --- | --- | --- |
| Gas | ETH | 原生资产 | 18 | 部署、写入和本链执行费都用 Base ETH |

| stable1 | USDT | `0xfde4C96c8593536E31F229EA8f37b2ADa2699bb2` | 6 | Base Standard Bridge 映射的 Ethereum USDT，不是 Tether 在 Base 原生发行 |

Base USDT 前端应标记为“桥接 USDT”，并确认用户使用的交易所是否支持直接充提该 Base 合约。

## 初始三池

三个协议池都以 Base 上的 DC 为一侧：

1. `DC / USDC`
2. `DC / bridged USDT`
3. `DC / WETH`

“创建池合约”不等于“注入流动性”。当前脚本默认只创建三池，`MAINNET_INIT_PAIRS=false`。2026-08-03 已确认 Base 精确复制 Ethereum 原始初始化：Treasury 50 亿 DC，三池依次为 500 万、5 亿、5 亿 DC，对手资产真实余额均为 1 个最小单位，其余为虚拟储备；初始 Base DC 总供应量为 60.05 亿。

## Base 的业务边界

- Base 是 ETH DAO 的副链执行层，不新建 Base DAO。
- Base 不部署 D、中本聪账户或分红模块；这三部分继续只在 Ethereum。
- Base Treasury 能接收 Base ETH 和任意 ERC-20；生产环境最终 controller 应为 Base `DualBridgeExecutorV2`，之后才永久锁定 bootstrap。
- ETH `CrossChainBroadcasterV2` 和 Base `DualBridgeExecutorV2` 接线、Base 路由激活、Factory 权限交接属于后续独立步骤。

## 已加入的安全门

- Base mainnet 部署必须显式设置 `BASE_MAINNET_PROTOCOL_DEPLOY=1`。
- 脚本在任何写入前检查 USDC、USDT、WETH 合约代码、symbol 和 decimals。
- 对 Base USDT 额外检查 `l1Token` 是 Ethereum USDT，`l2Bridge` 是 Base Standard Bridge。
- Base 不会继承 `.env` 中可能属于 ETH/BSC 的通用 `MAINNET_*` 资产和 Treasury 地址。
- 未显式确认流动性量时，不执行三池初始化。
- `base:economics:init` 默认只读；只有显式设置 `BASE_MAINNET_INITIALIZE=1` 才能写入。
- 初始化前要求 DC 总供应量等于 Treasury 与三个池子的可追踪余额之和；出现来源不明 DC、余额超目标、错误 token 顺序或异常虚拟储备会立即停止。
- 脚本按目标差额 mint，可从中断点安全续跑；完成并写入部署记录后永久进入 audit-only 模式，避免未来 Treasury 支出后被误补发。

离线生成 39 笔严格排序的交接 calldata：

`BASE_DEPLOYMENT_FILE=... BASE_EXECUTOR_ADDRESS=... BASE_DEPLOYER_ADDRESS=... npm run base:governance:plan`

交接后只读审计所有 owner/admin/role/bridge/allowed target：

`BASE_DEPLOYMENT_FILE=... BASE_EXECUTOR_ADDRESS=... npm run base:governance:audit`

两个工具均没有钱包和发送交易路径。

Gas 实测和经济参数草案见 `docs/Base_主网上线预算与经济参数草案_20260803.md`。

部署后先以只读模式生成精确初始化计划：

`BASE_DEPLOYMENT_FILE=deployments/base-mainnet-8453.json npm run base:economics:init`

仅在计划人工复核无误后，显式开启一次性写门：

`BASE_DEPLOYMENT_FILE=deployments/base-mainnet-8453.json BASE_MAINNET_INITIALIZE=1 npm run base:economics:init`

1. 给 `0xE88c63D29ECE76E3336B0Db747E10876c3bf9893` 准备至少 `0.01 Base ETH`、Base USDC 与指定桥接 USDT 各至少 1 个最小单位；当前三项均为 0。

4. 资产初始化和逐池验收通过后，再激活 Base 生产路由。
