DAO Proposal Parameters

DAO 用户提案参数控制板

这份文档面向 PM 和产品讨论，说明用户可以通过 DAO 提案调控哪些业务规则，以及每类规则的影响面大小。

只展示普通提案 本页只放用户可理解、可讨论的日常运营参数。
不展示底层权限 合约升级、权限迁移、国库、信用写入等不放在本页。

提案前提

发起 D 持仓达到席位门槛的用户，才有资格发起提案。
通过 普通参数按 D 投票通过，投票通过后进入执行。
执行 提案通过后，由 DAO executor / timelock 去调用链上函数。

1. 用户可以提案调整的参数

这一部分是建议开放给用户提案的业务规则。不是用户直接改，而是用户发提案，投票通过后由 DAO 执行。

模块 可提案调整什么 影响面 业务影响
Deal 交易 交易手续费比例、交易奖励比例。 高 直接影响用户交易成本、协议收入和奖励发放。
留言收费 是否开启留言收费、每条留言收多少 DC、是否把留言作为 burn 行为。 中 影响用户发消息成本，也会影响 DC 消耗速度。
创建合同收费 是否开启创建 deal 收费、创建 deal 收多少 DC。 中 影响开单成本，过高会降低创建量，过低则没有消耗约束。
身份 NFT 身份 NFT 铸造价格。 中 影响用户进入信用体系的成本。
OpenTokenToken B 方占坑后多久可以被 C 顶替。 中 影响开放币币交易的流畅度。太短容易误踢，太长容易卡单。
域名注册 域名注册价格、域名市场手续费比例。 中 影响域名系统收入、用户注册门槛和二级市场成本。
域名广告 最低广告充值、广告消耗速率、按比例扣费参数、未活跃踢出时间。 高 影响域名持有人收益、广告展示排序、充值用户的资金消耗速度。
Swap 手续费 DC/AUSD、DC/USDT、DC/AGI 等官方 pair 的 swap 手续费。 高 影响兑换成本、协议收入和做市体验。

2. PM 可以怎么设计提案入口

提案类型 适合放哪些参数 页面提示
普通参数提案 手续费、留言收费、创建收费、域名注册价、广告费率、顶替时间、NFT 铸造价。 提示“会影响用户成本或收益，投票通过后生效”。

3. 一句话版本

用户普通提案只调日常运营规则：手续费、奖励比例、留言收费、创建收费、NFT 铸造价、域名价格、域名广告参数、B 方顶替时间和 swap 手续费。
