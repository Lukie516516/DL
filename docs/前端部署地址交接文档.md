## 本次前端必须切换

1. 官方身份 NFT 地址切到新版 `DealInfoNFT`。
2. 信用读取切到新版 `DealCreditGraph`。
3. D 代币地址切到新版 `D`，`decimals() = 18`，`MAX_SUPPLY() = 100e18`，`SEAT_THRESHOLD() = 2.5e18`。
4. DAO / 分红读取切到新版 `DealNftGovernanceActivity`、`NftVetoRegistry`、`DealSeatVetoGovernor`、`VoteDividendClaimer`。
5. 身份 NFT 铸造价格读 `DealInfoNFT.mintPriceDL()`，当前为 `88e18`，表示直接 burn 88 DC。
6. `DealInfoNFT.pair()` 仅为旧 ABI 兼容字段，身份 NFT 铸造不再使用 pair 报价，也不再按 U/AUSD 折算。
7. “我的域名”调用 `DCDomainListReader.getDomainsByOwner(owner, offset, limit)`，按当前持有人查询。
8. 历史奖励、信用增量、交易过程时间线不要扫 logs，改读 `DealResultIndex.rewardOfDeal/getRewards/creditOfDeal/getCreditRecords/getTimeline`。
