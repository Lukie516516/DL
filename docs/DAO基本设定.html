Planned Governance

把 D 主网投票、主网分红、活跃 NFT 重大参与统一成一套明确规则

这份文档是计划改造版口径，用于产品、运营、前端和合约改造同步，不等于当前链上已经全部生效的治理实现。

一句话

D 固定 100 枚，18 位精度，1 D = 1% 分红权；参数调整和 treasury 打款只由 D 决定；升级和重大提案由 D 与当前活跃官方 DealInfoNFT 双院通过；持有 2.5 D 及以上保留一票否决权。

资产分工

DealCoin（DC）

协议主代币，负责交易奖励、支付、燃烧和生态流通。

D

协议权益代币，负责主网分红权、主网治理投票权、席位资格和一票否决权。

DealInfoNFT

官方身份 NFT，负责重大提案中的用户侧参与，一枚 tokenId 一票。

DC 负责生态流通。
D 负责主网协议权益。
DealInfoNFT 负责真实用户身份和重大治理中的用户侧参与。

D 代币规则

项目计划规则
总量固定 100 D
精度18 位
分红权1 D = 1% 分红权
席位门槛持有 2.5 D 及以上
席位权利可发起提案，保留一票否决权
发行链只在 ETH 主链
人话解释 持有 1 D = 拥有协议 1% 分红权。持有 2.5 D 或以上 = 拥有 DAO 席位资格。D 可以转让，但只影响未来分红和未来提案。

治理参与方

参与方适用范围计票规则
D 持有人 参数调整、treasury 指定打款、升级 / 重大提案 D-only 或重大案里的 D 院通过条件都统一为 赞成 D >= 70 D
当前活跃官方 DealInfoNFT 只参与升级 / 重大提案 赞成 NFT >= 当前活跃 NFT 快照总票数的 70%
当前活跃 NFT 定义 只认官方 DealInfoNFT；1 个 tokenId = 1 票；按提案创建时的快照计票；默认活跃窗口 90 天。

提案分层

提案类型 参与方 通过条件 投票期 投票期内否决规则
参数调整 只有 D 赞成 D >= 70 D 48 小时 投票期内任意合格 D 席位可一票否决
treasury 指定打款 只有 D 赞成 D >= 70 D 120 小时 投票期内任意合格 D 席位可一票否决
升级 / 重大提案 D + 当前活跃 NFT 赞成 D >= 70 D，且赞成 NFT >= 当前活跃 NFT 快照的 70% 120 小时 投票期内任意合格 D 席位可一票否决
席位一票否决 只要地址在否决快照时持有 2.5 D 或以上，就保留一票否决权。否决在投票期内即可发生；任意合格席位否决，提案立即失败，不再额外设置通过后的否决窗口。

分红与主链边界

项目规则
D 发行只在 ETH 主链
D 投票只在 ETH 主链
D 分红只在 ETH 主链
分红资产统一使用主网 DC
recognized 资产继续按当前逻辑进入 pair，不算 treasury 分红来源
非主网 Deal / DC可以运行，但不承载 D 治理和 D 分红
 
1. 主网 treasury / dividendSource 收资产。
2. 可安全兑换的资产换成主网 DC。
3. D-only 提案投票通过且未被席位否决。
4. executor 创建分红轮。
5. D 持有人按主网 D 快照领取主网 DC。
普通席位可以发起分红相关提案，但不能绕过 DAO 直接创建分红轮。
